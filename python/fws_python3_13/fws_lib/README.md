# fws_lib (Fugashi WorkShop 共通ライブラリ)

## 概要
`fws_lib` は、Fugashi WorkShop ツール群（`fws_apps`）の各アプリケーションから共通して利用される汎用機能や定数を提供するライブラリパッケージです。
コードの重複（車輪の再発明）を防ぎ、アプリ全体の品質と開発効率を向上させることを目的としています。

## 構成
本ライブラリは以下の層（ディレクトリ）から構成されます：

* **`constant/`**: アプリケーション間で共通利用する定数（ライブラリバージョン、デフォルトエンコーディング等）。
* **`common/`**: 特定のGUIに依存しない汎用ロジック（エラーハンドリング、ログ出力、ファイル操作、JSON操作、文字列・データ加工等）。
* **`tkinter/`**: Tkinterを用いたGUIアプリに特化したユーティリティ（ウィンドウ制御、ウィジェット操作、ダイアログ表示、スタイル管理等）。
* **`core/`**: （※将来の拡張用）データベースエンジンや通信基盤などのコアロジックを配置。

## 開発規約
* `fws_lib` 内のモジュールは、外部アプリからインポートして利用されることを前提としているため、**他アプリへの依存を持たせない**ようにしてください。
* FWSの基本コーディング規約（`python3_13_general.md`）に準拠し、引数・戻り値の型ヒント付与、Docstringの記述を徹底しています。
