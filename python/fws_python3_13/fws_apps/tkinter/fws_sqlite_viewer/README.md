# FWS SQLite Viewer

FWS SQLite Viewer は、FWSアーキテクチャ（View / Event / Logic / Businessの完全分離）に基づいて構築された、軽量なSQLiteデータベース閲覧・クエリ実行ツールです。

## 特徴
- **テーブル構造の閲覧**: データベース内のテーブル一覧と、各テーブルのスキーマ（カラム名、データ型、プライマリキー等）を確認できます。
- **複数データベースの常駐・同時管理**: `ATTACH DATABASE` を用いて、複数のSQLiteファイルを1つのツリー上に階層表示し、横断的に管理・クエリ実行が可能です。
- **セッション自動復元**: アプリを終了しても、次回起動時に前回のDB接続状態（メインDBおよびアタッチ済みDBのパス）を自動的に復元します。
- **クエリの実行**: 任意のSQL（SELECT, INSERT, UPDATE, DELETE等）を入力・実行し、結果をデータグリッドで確認できます。
  - **選択範囲の実行**: テキストをハイライト（選択）して実行することで、特定のクエリのみを素早く実行できます。
  - **複数クエリの一括実行**: セミコロン (`;`) で区切られた複数のSQL文を一度に実行し、エラー時は安全にロールバックします。複数実行時は結果の履歴一覧が別ダイアログでポップアップします。
  - **外部ファイルの一括実行 (source)**: `source <ファイルパス>;` で指定された外部SQLスクリプトを一括実行します。（通常のSQL文との混在・連続実行も可能です）
  - **CSV/TSVファイルの一括インポート (load)**: `load <ファイルパス> into <テーブル名>;` で指定されたCSV/TSVファイルを対象テーブルに高速インポートします。
- **オートインデント機能**: SQL入力エリアでは、前行のインデントを引き継ぐオートインデントに対応しています。
- **クリップボード連携**: 
  - テーブル名や単一セルのダブルクリックによる素早いコピー。
  - `Ctrl + C` による複数行のTSV一括コピー。
  - `Ctrl + Shift + C` によるカラム名（ヘッダー）を含めたTSV一括コピー。
- **堅牢なアーキテクチャ**: FWSアーキテクチャに則り、メイン画面だけでなく子画面（ダイアログ等）においても画面レイアウト（UI）とイベント処理、ビジネスロジックが完全に分離されており、単体テスト（自動テスト）による品質保証が行われています。

## 前提条件
- Python 3.13 以上
- 外部ライブラリ（pip install）は不要です。すべてPython標準ライブラリ（`tkinter`, `sqlite3`, `unittest`等）で動作します。

## 開発とテスト
当プロジェクトは品質保証のため単体テストを完備しています。テストは以下のスクリプトでシナリオ順（1〜25）に実行・確認できます。
```powershell
python fws_apps/tkinter/fws_sqlite_viewer/tests/run_all_tests.py
```

## 起動方法
プロジェクトルート（`fws_python3_13`）から、以下のコマンドを実行するか、直接ファイルをダブルクリックして起動します。

```powershell
python fws_apps/tkinter/fws_sqlite_viewer/fws_sqlite_viewer.pyw
```
※拡張子が `.pyw` になっているため、コマンドプロンプトの黒い窓を残さずにGUIアプリとして起動します。

## 使い方
1. **データベースを開く**
    - 画面上部の「Open DB」ボタンをクリックし、閲覧したい `.db` や `.sqlite` ファイルを選択します。
    - または、直接テキストボックスにパスを入力してEnterキーを押します。
1. **テーブルとスキーマの確認**
    - 左側のリストにテーブル一覧が表示されます。
    - テーブル名をクリックすると、右上のパネルにそのテーブルの構造（スキーマ）が表示され、同時に「全件取得（SELECT *）」のクエリがSQL入力エリアに自動セットされます。
1. **SQLの実行**
    - 画面中央のテキストボックスにSQLを記述し、「Run Query」ボタン（または `Alt + X`）を押すと、結果が下部のデータグリッドに表示されます。
