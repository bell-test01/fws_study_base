# fws_case_recorder

## 概要
日々の案件対応や作業の記録を迅速に残し、後から柔軟に検索・参照するためのデスクトップアプリケーションです。
頻繁に使用する文章の定型文化や、ワンクリックでの時刻・記号挿入によって、キーボードでの入力を強力に補助します。

## 主な機能
- **記録作成・管理**: 県域・ビル名・案件番号とともに作業内容を記録。
- **入力補助**: 矢印（→、←）、引用線（---）、現在時刻のワンクリック挿入。
- **定型文管理**: よく使う文章を登録し、クリック一つで呼び出し可能。
- **曖昧検索と履歴編集**: 過去の記録を検索し、アコーディオンUIで展開してそのまま追記・修正が可能。
- **コンパクトUI**: 画面の隅に配置しやすいコンパクトなレイアウトと、作業を邪魔しない透過度・最前面表示機能を搭載。

## 起動手順
以下のコマンドを実行してアプリケーションを起動します。

```powershell
python fws_case_recorder.pyw
```
